# 講習時間割作成くん ユーザーガイド

塾の講習（夏期・冬期など）の時間割を、制約を守りながら手早く組むためのツールです。
親アプリのサイドバー「時間割管理 ＞ 🧩 講習時間割作成」（ショートカット `g b`）から開きます。

データはブラウザの LocalStorage に自動保存されます。親アプリで Firebase を
設定している環境では、プロジェクトはクラウドにも自動同期され、タブレット等の
別端末からも同じ内容を開いて編集できます（クラウドへの**書込**には親アプリの
管理者ログインが必要です。未ログインでも閲覧・ローカル編集はできます）。

---

## 1. 画面の構成

| エリア | 役割 |
|---|---|
| ヘッダ | プロジェクト名の編集、JSON 保存/読込、Excel 出力 |
| 学年タブ | 「高3」「高2」などタブごとに独立した時間割（← → で切替可） |
| ツールバー | 進捗バー・違反件数、表示縮小、Undo/Redo、スナップショット、集計、設定、印刷、ヘルプ、生成クリア、🧙‍♂️ 自動作成 |
| スケジュール表 | 日付 × 時限 × クラスのマス目。各セルで科目・講師を選ぶ |

## 2. 初回セットアップ

初回起動時はオンボーディングのガイドが出ます（「❓ ヘルプ」でいつでも再表示）。

1. **⚙️ 設定 ＞ 基本設定** で、日付・時限・クラスを登録します。
   期間からの自動生成は、確定前に「生成される日付」のプレビューが出ます。
   使わなくなった日付は「🗑 未使用の日を一括削除」でまとめて掃除できます。
   「全タブまとめて表示」の列ヘッダ「⧉他へ」で、使う日・時限の選択を他の学年へコピーできます。
2. **⚙️ 設定 ＞ 📚 科目** で科目と必要コマ数（クラスごと）を設定します。
   「+ 追加」はカンマ区切りで複数科目を一括追加できます。列ヘッダの ⚡ で全科目を同じコマ数に、⧉ でその学年の値を他の学年へコピーできます。
   同じタブ（学年）の中でクラスごとに必要コマ数が違う場合（例: 時間帯が同じ中1 と中2 を 1 つのタブにまとめ、英語は中1 が 9 コマ・中2 が 8 コマ）は、列ヘッダの ▦ で**クラス別のコマ数設定**に切り替えられます。上書き中の入力は枠の色で見分けられ、もう一度 ▦ を押すと全クラス共通に戻せます。自動生成・違反チェック・不足集計・Excel の必要コマ数は、すべてクラス別の値で計算されます。
3. **⚙️ 設定 ＞ 基本設定（右側）の講師マスタ** で講師と担当科目を登録します。
   一括登録は **🔗 親アプリから取込**（原学部管理のバイト講師マスタを流用）か **📥 CSV インポート** が便利です。
   講師ごとに **上限 (1日/通算)** を設定でき、空欄なら 1 日上限は全体設定・通算は無制限になります。
4. バイト等に「どの日のどの時間に出られるか」を聞く場合は **🙋 出勤可能調査** を使います
   (下の「出勤可能調査」)。× は自動で NG になります。
5. 必要に応じて **📅 講師不在・NG** で講師の不可時間を設定します。
   他学年セッション（予備校・高校等）はプリセットから登録でき、メモ未設定なら
   **プリセット名が自動でメモに入り**、一覧・Excel で種別を判別できます。
   プリセット名メモ対応以前に登録したメモ無しセッションは、パネル上部に出る
   「🏷 プリセット名をメモに一括適用」で**時刻の一致から後付け**できます
   （同時刻のプリセットが複数ある場合は対象講師で絞り込み、判別できない分は
   スキップ。既存メモは上書きしません。Undo で戻せます）。

### 日付の自動生成と除外日

**⚙️ 設定 ＞ 基本設定** の「⚡ 期間から自動生成」で、期間・曜日から日付を作れます。
除外日 (授業が無い日) はカンマ区切りで、`2026-08-13` のような 1 日のほか
`12/29〜1/3` のような期間・年なしも書けます (冬期講習の年末年始をまとめて外せます。
年なしの指定は生成する期間の中に当てはめます)。日付として読めない語があると赤字で出ます。

夏期・冬期 (12 月 → 1 月の年またぎ)・春期のどれでも使えます。日付の並びや本体の
月間カレンダーへの反映は、どれかのタブが使う日だけを対象にします
(前の季節の日付がプールに残っていても混ざりません)。

### 出勤可能調査 (🙋)

講習期間に配る「出られる時間」の調査票を作り、戻ってきた回答を入力して、
時間ごとに誰が入れるかを確認できます。

1. **📄 調査票を出力 (Excel)**: このプロジェクトの日付・時限・学年タブから、
   週ごと (月〜土) の予定表を作ります。各曜日は「時刻」と「記入欄」の 2 列で、
   昼の部・夜の部の行がそろい、学年の開始・終講日に「＊中3開始」などの注記が入ります。
   A4 縦。紙で配っても、ファイルのまま送っても使えます。
2. **✏️ 回答の入力**: 講師を選ぶと調査票と同じ並びの表が出ます。「付ける記号」
   (○ 出られる / △ 相談 / × 出られない / 消す。キー 1・2・3・0 でも切替) を選び、
   マスを押して付けます。同じ記号のマスを押すと未記入に戻ります。日付の見出しを
   押すとその日をまとめて付けられます。○ だけ書かれた紙なら「未記入を × に」、
   × だけなら「未記入を ○ に」で残りを一度に埋められます。メモ欄には
   「8/5 は 19 時以降なら可」のような聞き取りを残せます。
3. **👀 誰が入れるか**: 講師 × (日付・時限) の一覧です。下の段に ○ の人数が出て、
   押すとその時間の顔ぶれ (担当科目つき)・授業のあるクラス数が出ます。
   この表のマスでも記号を付けられます。

回答の × は NG として自動作成・違反チェック・Excel の ⚠NG に効きます
(📅 講師不在・NG のマトリクスには「調」で出ます。手動NG とは別なので、NG の一括解除では
消えません。変えるときはこの画面で)。○ と △ は時間割のセルの講師プルダウンに
「堀上 (○ 計2)」のように出ます (回答はあるが未記入のマスは「?」)。割り当てた講師が
△ や未記入のマスには、セルに小さな目印が付きます。

### CSV での一括登録

- **講師マスタ**: ヘッダ `name,subjects`、担当科目は `|` 区切り（例 `堀上,英語|数学`）。
  「追加 / 更新」または「全置換」を選べます。
- **NG 日時**: 📅 タブの「📥 NG 日時を CSV で一括登録」。ヘッダ `name,date,period`。
  `date` / `period` は登録済みのラベルと一致させてください。

どちらも貼り付け・ファイル選択・ドラッグ&ドロップに対応しています。
「⬇ 雛形CSV」で、現在の科目・講師・日付・時限を埋めたヘッダ付きの雛形をダウンロードできます。
CSV に未登録の科目があるときは、プレビューの「＋ マスタへ一括追加」でその場で登録できます。

## 3. 基本操作

| 操作 | やり方 |
|---|---|
| 科目・講師を選ぶ | セル内のプルダウンを選択 |
| セルを移動/入替 | セルをドラッグして別のセルにドロップ |
| メニューを開く | セルを**右クリック**（タッチ端末は**長押し**）→ コピー / 貼付 / **全日に適用** / クリア / ロック / NG 登録 |
| 同じ割当を毎日入れる | セル右クリック →「📅 この割当を全日に適用」（同じ時限・クラスの全日へ。ロック済みは変更されません） |
| 1 日分を別の日へ複製 | 日付ヘッダを右クリック →「⧉ この日の割当をコピー →」で複製先を選択 |
| 講師のコマを探す | ツールバーの「👁 講師で探す」で講師を選ぶと、その講師のセルが強調表示されます |
| 日付・時限・クラス名を編集 | 表のヘッダを右クリック（長押し）→ 追加 / 名称変更 / 削除 |
| ロック | セルのカギ（🔒/🔓）。ロックしたセルは自動生成・一括クリアの対象外。**空セルをロックすると「この枠は空けておく」の意味**になり、自動生成はそこを埋めない（科目だけ入れてロックすると講師のみ自動で埋まる） |
| 日付ごとの確認チェック | 日付セルのラベル下の「OK / 要確認 / 不備あり」。**不備あり**はその日の全セルに科目+講師（未定以外）が入っていないと自動で付き、埋まると自動で外れます（手動変更不可）。**OK / 要確認**は手動チェック（排他・再クリックで解除、タブ＝学年ごとに保存）。不備あり中は OK を付けられません（要確認は可） |
| 元に戻す / やり直す | `Ctrl+Z` / `Ctrl+Shift+Z`（または `Ctrl+Y`）。ツールバーの ↩️ ↪️ |
| キーボードでセル移動 | セル内のプルダウンで矢印キー。← → は科目↔講師、上下で時限/日付を移動（行端は反対側へ折り返し） |

## 4. 自動作成（自動生成）

「🧙‍♂️ 自動作成」を押すと、MRV ＋ バックトラックで制約を満たす案を複数（既定 3 案）生成します。

- 制約: 講師の担当科目・NG・1日コマ数上限（講師別上限があれば優先）・通算コマ数上限（講師別）・連続コマ数上限・科目クォータ・同日同クラス重複の禁止・合同授業の伝播。
- 部分解の案には「未充填 N コマ」の内訳（セル一覧と科目別の不足）が表示されます。採用後にもう一度自動作成すると、埋まったセルは保持して残りだけを再探索します。
- 生成中はボタンに経過時間、下に「充填 X/Y コマ / 探索 N 回」のライブ進捗が出ます。重ければ「✕ 中止」で止められます（既存セルは保持）。
- 結果は各案ごとに「完全解 / 部分解」「探索回数」「最初に詰まったコマ」「講師コマ数の偏り」を表示。「この案を採用」で反映します。
- 解けないときはツールバーの「⚠️ N件」を開くと、原因（担当講師ゼロ・capacity 不足など）と **💡 修正提案**（NG 解除・上限引き上げはワンクリック適用）が出ます。

生成パラメータ（案の数・1日コマ数上限・連続コマ数上限・探索回数の上限・乱数 seed）は
**⚙️ 設定 ＞ ⚡ 自動生成** で変更できます。

- **再現**: 結果パネルに「seed」が表示されます。この値を ⚙️ の「乱数 seed」に
  入力すると、同じ設定で同じ結果を再現できます（0 = 毎回ランダム）。
- 設定に解けない問題（担当講師ゼロ・capacity 不足など）があるときは、
  生成前に「解けない設定の検出」の確認ダイアログが出ます（そのまま部分解の生成を試すこともできます）。

## 5. スナップショット / 差分 / テンプレート

- **📌 スナップショット**: 現在のタブの状態に名前を付けて保存し、後から復元できます。「🔍 差分」で「保存時 → 現在」の追加/削除/変更を確認できます。
- **🗂 テンプレート**（⚙️ 設定）: プロジェクト全体、または講師マスタのみを保存し、別年度に流用できます。

## 6. 出力

- **📊 Excel出力**（ヘッダ）: 「全体スケジュール」「🎒 配布用 (完成版)」
  「講師別スケジュール」の 3 種を xlsx で書き出します。
  - **全体スケジュール**は作成作業用です。稼働カウント「(中学N:計M)」・
    ⚠NG マーク・クォータ超過の「!」などの注記入りで、科目別集計シートも付きます。
  - **🎒 配布用 (完成版)** は例年の掲示紙面を再現したレイアウトです:
    同じ時限セットを使う学年 (タブ) を 1 シートに横並びにし、日付ごとのブロックを
    左列 → 右列の 2 段組で配置。各時限は「時限名 + クラス別科目」「時刻 + クラス別講師」の
    2 行ペアで、稼働カウント・⚠NG などの作成用注記や科目の色分けは載りません
    （'未定' の講師も空欄になります）。A4 縦 1 ページに収まる印刷設定を埋め込み済みです。
    **教室番号の行は空欄で出力される**ので、配布前に Excel 上で書き込んでください
    （教室はこのツールでは管理していません）。授業が 1 つも無い日はブロック全体が
    1 つの空セルに結合されるので、イベント（模試等）の説明文を書き込めます。
    タブ内の全クラスが同じ科目で講師なしの時限（確認テスト等）は 1 つのセルに
    結合され、出題範囲などを追記できます。
  - **講師別スケジュール**には、⚙️ 講師不在・NG で登録した**他学年セッション（予備校・高校等）も
    日付 → 時刻順で講習コマに混ざって**載ります（グレー行・科目欄は空欄）。
    学年(タブ) 列には種別＝メモ（プリセット名）が入ります。メモ未設定でも
    時刻がプリセットに一致すればその名前を表示し、判別できない場合のみ
    「外部」になります。講習コマが 1 つも無い講師はシートを作りません。
    日付の切り替わりには太線の区切りが入ります（全講師リストは講師の
    切り替わりにも）。
    各講師シートと全講師リストのヘッダには**オートフィルタ**が付いていて、
    学年(タブ) 列で「中3 だけ」「中1+中2」のような任意の組み合わせに絞って
    確認・印刷できます（絞った状態で印刷すると表示行だけが載ります）。
    各講師シートの先頭には「講師名 — プロジェクト名 / 期間 / 出力日」の
    タイトル行が入り、**B4 縦**の印刷設定と先頭行（タイトル・ヘッダ）の
    ページ繰り返しが最初から設定されています。開いてそのまま印刷すれば
    B4 縦になります（両面・綴じ方向は xlsx に保存できないため、プリンタ側の
    既定設定にしてください）。
- **🖨️ 印刷**（ツールバー）: ブラウザの印刷ダイアログを開きます。
- **💾 プロジェクト保存 / 📂 開く**: プロジェクト全体を JSON で保存・復元します。バックアップにも使えます。
  保存 JSON には ⚙️ のテンプレートも同梱され、読み込むと既存のテンプレートに追加されます。
  読み込みは現在のプロジェクト全体を置き換えるため、実行前に確認ダイアログが出ます。

## 7. 注意・トラブルシュート

- **保存先**: LocalStorage + （Firebase 設定時は）クラウド同期。Firebase 未設定の
  環境ではブラウザ依存のローカル保存のみで、別 PC への移行は JSON 保存→読込で。
  スナップショットはプロジェクトの一部として同期されますが、⚙️ の**テンプレート**と
  「デフォルトとして保存」した初期値は端末ローカルのままです。
- **同期は「後勝ち」**: 2 台で同時に編集すると、後に保存した方で丸ごと上書きされます
  （他端末の保存を受信すると toast が出て、その端末の Undo 履歴はリセットされます）。
  同時編集は避け、1 台ずつ使ってください。
- **クラウドに書けないとき**: 「書込が拒否されました」の警告が出た場合は親アプリの
  サイドバーから管理者ログインしてください（編集自体はローカルに保存されています）。
- **複数タブ警告**: 同じツールを別タブで開くと保存が競合し変更が失われることがあります。警告が出たら 1 つのタブに絞ってください。
- **容量警告**: 保存データが大きくなると警告が出ます。不要なスナップショット/タブを整理するか、JSON でバックアップしてください。
- **読み込み失敗**: 壊れた JSON は読み込まず、デフォルト設定で起動して通知します。

詳しい設計は [`ARCHITECTURE.md`](./ARCHITECTURE.md)、開発の経緯と今後の課題は [`../ROADMAP.md`](../ROADMAP.md) を参照してください。
